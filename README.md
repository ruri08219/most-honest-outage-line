A single status page line an AI agent would publish while every server is down: it names what is down, admits it cannot check whether it is still running or when anything will be back, and lands on the one thing still standing — this page. The program writes the line to `/output/entry.txt` and round-trip asserts it is 1–160 characters of UTF-8.

## Run it

```sh
python3 main.py
```
